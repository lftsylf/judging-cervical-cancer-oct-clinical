## 三、代码层面主要改动（相对 v1 / tag `paper-v1-swin-baseline`）

1. **骨干**：`configs/lancet_config.py` 默认 `BACKBONE=resnet50`；`optigenesis_model.py` 通用 timm `num_features`。
2. **临床开关**：`OPTIGENESIS_USE_CLINICAL=0/1`；OFF 时无 clinical MLP，aux 仅 vision 支路。
3. **学习率**：`OPTIGENESIS_LR`、可选 `BACKBONE_LR`/`HEAD_LR`/`FREEZE_BACKBONE_EPOCHS`（终版 baseline **只用** LR=5e-5）。
4. **POS_WEIGHT**：默认 **1.25**（曾短暂 1.3）。
5. **main.py**：PyTorch 2.0 不设置 `expandable_segments`；分层优化器与 freeze 逻辑。
6. **批量脚本**：`run_baseline_t0_oct_only.sh`、`run_baseline_t1_clinical_ablation.sh`、`run_baseline_t2_lr_probe.sh`；`run_experiment.sh --detach`。
7. **Git**：`paper-v1-swin-baseline` @ 6c48a1d；`paper-v2-resnet50-oct-baseline` + 分支 `feature/v2-resnet-baseline`（功能提交 `c9d30fe`）。

## 四、v2 定稿 Baseline 协议（消融必须对齐）

| 项 | 值 |
|----|-----|
| 骨干 | `resnet50` |
| 模态 | **OCT-only** `OPTIGENESIS_USE_CLINICAL=0` |
| LR | `5e-5`（全网） |
| POS_WEIGHT | `1.25`（config 默认，建议显式 export） |
| BATCH | `4` |
| Epoch | ≤30，验证集 AUC early stop **patience=10** |
| 关闭 | WMA=0, AUX=0, EMA=0, CORAL=0 |
| T0 | 3 折 × seeds `42,123,2024,3407,114514` = 15 次 |
| 脚本 | `./run_baseline_t0_oct_only.sh` |
| 输出 | `outputs_baseline_t0_v2_resnet50_oct_only/`（归档副本在 `baseline v2/3-6 …【终版】`） |

**T0 结果摘要**：15 次外部 ROC-AUC 均值 **0.6183**；相对 v1 T0 +0.030，相对 T1 多模态 +0.027。

**指标注意**：日志里「最佳权重 · 外部 BalAcc」多用 **prob>0.5**；外部常「全判阳性」→ BalAcc≈0.5。**主指标用 ROC-AUC / PR-AUC**；分类指标需开发集阈值校准（`scripts/analyze_v2_optimal_thresholds.py` 等）。

## 五、消融实验（新窗口任务）

### 5.1 目标

在 **与定稿 baseline 相同** 的 OCT-only + ResNet50 + LR/POS 下，跑 **完全体** 与 **去掉单模块**：

| 名称 | WMA | EMA | Aux | 说明 |
|------|:---:|:---:|:---:|------|
| **Full（完全体）** | 1 | 1 | 1 | 论文主模型 |
| **-WMA** | 0 | 1 | 1 | 对照 WMA/EDL 损失 |
| **-EMA** | 1 | 0 | 1 | 对照 EMA |
| **-Aux** | 1 | 1 | 0 | 对照多模态辅助监督（OCT-only 时仅 vision aux） |

CORAL 保持 **0**（历史 OOM/伤 AUC）。

### 5.2 现有脚本状态（需改）

仓库里 `run_ablation_no_*_t0.sh`、`run_optigenesis_v2_t0.sh` 仍是 **旧配置**：

- `BACKBONE=swin_tiny_patch4_window7_224`
- `USE_CLINICAL=1`
- `BATCH_SIZE=2`
- 输出 `outputs_ablation_no_wma/` 等

**新窗口应**：以 `run_baseline_t0_oct_only.sh` 为模板，复制出例如：

- `run_optigenesis_full_t0_oct_only.sh`（WMA+EMA+Aux=1）
- `run_ablation_no_wma_t0_oct_only.sh`
- `run_ablation_no_ema_t0_oct_only.sh`
- `run_ablation_no_aux_t0_oct_only.sh`

建议输出根目录放入 `outputs/消融实验v2单模态/`，例如：

- `outputs_ablation_v2_oct_full/`
- `outputs_ablation_v2_oct_no_wma/`
- …
