## 分类速查

| 前缀 | 用途 |
|------|------|
| `run_baseline_*` | v2/v3 baseline / LR 探针 / 临床 on-off |
| `run_ablation_*` | WMA/EMA/Aux 消融与 only-* |
| `run_comparison_*` | 骨干 SOTA 对比 |
| `run_optigenesis_*` / `run_wma_*` | Full / 早期 WMA 试跑 |
| `*_lib.sh` | 被 source 的共享库，勿单独当入口（除非文档写明） |

带 `oct_only` 的为 v2/v3 单模态定稿协议；无此前缀、且注释写「已废弃/重定向」的为 v1 兼容壳。
