## 模型技术说明书（请严格据此构图）

### 0. 图要表达的一句话

宫颈 OCT：12 点位 × 每点多帧 → 共享视觉骨干 + 帧级证据深度学习 → **窗内**按不确定度加权聚合成窗分 →（推理时）**窗间**对六窗概率取平均 → 患者级连续分；训练另有主损失与 MIL 辅损，EMA 仅作参数平滑注记。

### 1. 建议分区（学图一，不是左中右三大说明书）

- **区 A（左）**：输入与组袋/切窗（数据组织）
- **区 B（中）**：共享编码（ResNet 展开 + EDL 推导链）——视觉主体应紧凑
- **区 C（右）**：聚合与决策（训练损失支路 + 推理六窗平均）——创新重点，可比 B 更密
- 右下角：**图例**（线型含义）

比例建议：A ≈ 20%，B ≈ 30%，C ≈ 45%，图例 ≈ 5%。B 不要做成巨型柱。

### 2. 符号表（箭头上必须出现这些）

| 符号 | 含义（表注用短中文） |
|------|----------------------|
| X_{i,t} | 点位 i 第 t 帧图像 |
| F_{i,t} | 该帧视觉特征 |
| e_{i,t} | 帧级证据 |
| α_{i,t} | 狄利克雷参数 |
| u_{i,t} | 帧不确定度 |
| p_{i,t} | 帧阳性概率 |
| w_{i,t} | 不确定加权得到的帧权重 |
| p^{(k)} | 第 k 窗患者倾向分，k=1..6 |
| p_pat | 患者级连续分 |
| L_main | 患者级主损失 |
| L_MIL | 帧级多示例辅损 |
| θ / θ_EMA | 当前参数 / EMA 平滑参数 |

### 3. 区 A：数据（少文字，靠小图标 + 短标签）

**输入示意**：圆环 12 点；表注「12点位OCT，每点多帧」。

**训练支路（上路）**

- 规则用两行极短标签即可：
  - 阴：随机 2 点
  - 阳：优先阳性点，不足补齐至 2
- 输出袋：表注「训练袋 n=2×全帧」
- **一条**粗实线进入区 B，箭头标注：`X_{i,t}`

**推理支路（下路）**

- 表注「6个不重叠窗」
- 窗 k 含 2 点全帧
- **六条**粗实线进入区 B（可画成汇入同一骨干的并行），箭头标注：`X^{(1)} ... X^{(6)}` 或 `X^{(k)}`

### 4. 区 B：共享网络（展开 + 推导链）

#### 4.1 ResNet50（层数必须不同）

用紧凑梯形/堆叠小块表示，**块数反映真实深度**，不要四块一样大：

1. 茎干：7×7 卷积 + 最大池化（很小）
2. **残差阶段1**：3 个瓶颈块（示意画 3 层薄片）
3. **残差阶段2**：4 个瓶颈块（画 4 层，略长）
4. **残差阶段3**：6 个瓶颈块（画 6 层，明显最长）
5. **残差阶段4**：3 个瓶颈块（画 3 层）
6. 全局平均池化 → 帧特征 `F_{i,t}`

箭头链示例（每段都标变量）：

`X_{i,t} → F1 → F2 → F3 → F4 →(GAP)→ F_{i,t}`

旁注极小：「骨干 ResNet50（可训练）」；可用火焰小标表示可训练（学图一），不要大段文字。

#### 4.2 EDL：画「流水线」，禁止公式清单墙

从 `F_{i,t}` 向右/向下画 4 个小节点（每个节点标题 ≤ 6 字，公式一行）：

1. **证据头**：`F_{i,t} → e_{i,t}`（非负证据）
2. **狄利克雷**：`α_{i,t} = e_{i,t} + 1`
3. **强度**：`S_{i,t} = Σ α_{i,t}`
4. **分解输出**（三叉射出，箭头都标符号）：
   - `u_{i,t} = K / S_{i,t}`（不确定度）
   - `p_{i,t}`（帧阳性概率，由归一化证据得到）
   - `α_{i,t}`（后续聚合可用）

要点：让读者看见 `F ⇒ e ⇒ α ⇒ (u, p)`，而不是四个并列公式框。

### 5. 区 C：聚合与输出（参数流为主）

#### 5.1 共用的关键模块（双实线边框）

**窗内不确定加权聚合**（只对同一袋/窗内的帧）：

- 入：`{u, α}`（或 `{u, p}`，按实现；本方法对帧证据做加权聚合）
- 节点公式（短）：`w = softmax( (1 - u) / τ )`
- 出：窗分 `p^{(k)}`（训练时写作 `p_bag`）
- 箭头标注：`u,α → w → p^{(k)}`

#### 5.2 训练路径（上路，少字）

- 1 路：`F ⇒ EDL ⇒ UWA ⇒ p_bag`
- 从 `p_bag` / `α` 引出细虚线到：
  - `L_main`（表注：患者级证据分类）
  - `L_MIL`（表注：阳性袋至少一处够阳）
- 可写极小：`L = L_main + λ L_MIL`
- EMA：不要进主链；角注「θ_EMA：验证/测试用平滑参数」

#### 5.3 推理路径（下路，少字）

- 6 路并行：每窗一个小型 UWA，出 `p^{(1)}, …, p^{(6)}`（箭头上写符号，框内只写「UWA」）
- 汇入双实线模块：**六窗平均**
  - 公式节点：`p_pat = (p1 + … + p6) / 6`
  - 极小分层表注（唯一允许的一句说明）：「UWA=窗内；Mean=窗间」
- 终点：`p_pat` → 表注「患者连续分（ROC/AUC）」
- 不要在终点写长文；若要写只留半行：「硬分类另设阈值；AUC 扫全阈值」

### 6. 线型图例（黑白友好）

- 粗实线：特征/张量 X, F
- 细实线：概率/不确定度/权重 p, u, w
- 细虚线：损失 L
- 双实线框：关键模块（UWA、六窗平均）

颜色：仅浅灰蓝/浅米色底分区，**不**用颜色区分训练/推理（用上下位置 + 标签「训练」「推理」）。

### 7. 明确禁止

Attn、WMA、临床多模态、知识库、GRU、把 Mean 画成再做一次不确定加权、巨型 ResNet 空心标题、框内说明书式长句、箭头无变量。

### 8. Gemini 自检（写提示词前先过一遍）

2. 阶段3是否明显比阶段1/4「更厚/更长」（6 块 vs 3 块）？
3. EDL 是否是 `F → e → α → (u,p)` 链条？
4. 右侧是否主要是 `w, p^{(k)}, L, p_pat` 而不是段落？
