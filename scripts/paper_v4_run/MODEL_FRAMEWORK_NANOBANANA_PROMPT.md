## 复制起点（提示词正文）

使用 Nano-Banana 2 Pro 生成一张横向学术框架图（白底、浅色分区、黑白印刷友好）。信息密度高，模块内短标签，**禁止课件式长句**。每条主箭头必须标注数据符号。

**主标题（整图正下方居中）：**  
图1. 宫颈 OCT 患者级筛查整体框架（点位袋 · 帧级 EDL · 窗内不确定加权 · 六窗平均）

**总布局（左→右三区，比例约 22% / 33% / 40%，右下角留图例）：**

- **区 A（左，极浅蓝底）**：数据组织——训练组袋 / 推理切窗  
- **区 B（中，极浅灰底）**：共享编码——**展开的 ResNet50** + **EDL 推导链**  
- **区 C（右，极浅杏底）**：创新重点——**窗内 UWA** 与 **窗间 Mean**；训练损失；EMA 仅角注  

禁止出现：Attn、WMA、临床表格、知识库、GRU；禁止把 Mean 画成第二次不确定加权；禁止把 EMA 画成与图像平行的处理支路；禁止把 MIL@0.3 画成末端「MIL 分类器」。

---

### 区 A｜数据输入（标题：A. 位点袋与扫描窗）

**上路 · 训练（粗实线）：**

1. 左侧小图标：宫颈 12 点圆环示意；短标签「12 点位 OCT · 每点多帧」。  
2. 组袋规则（两行极短）：「阴：随机 2 点」「阳：优先阳点，不足补齐」。  
3. 两个轻微错开的矩形叠放 = 训练袋；醒目标注 **n=2×全页**。  
4. 一条粗实线箭头进入区 B，箭头上标注：\(X_{i,t}\)。

**下路 · 推理（粗实线，略细于训练或并行示意）：**

1. 短标签「6 个不重叠窗」。  
2. 窗 \(k\)：2 点 × 全帧。  
3. 六条粗实线汇入同一骨干（可画成并行汇合），箭头标注：\(X^{(k)}\)（\(k=1..6\)）。

区 A **不要**画 Backbone / EDL（那些在区 B）。

---

### 区 B｜共享编码（标题：B. ResNet50 骨干与帧级 EDL）

#### B1. 视觉骨干 ResNet50（必须展开，各阶段外观不同）

横向紧凑流水线，**用堆叠薄片数量体现深度差异，禁止四个一样大的空心「阶段」盒子**。参考上一版「输入预处理 → 茎干 → 残差 → GAP」气质，但阶段要画全、画异：

1. **输入预处理（小虚线框）**  
   - 标签：多帧 OCT 展开  
   - 入：\(X_{i,t}\)

2. **茎干（小实线框，很矮）**  
   - 标签：Conv 7×7, 64 + MaxPool  
   - 旁注极小：可训练（可用小火焰标）

3. **残差阶段 1（画 3 层薄片，最短之一）**  
   - 标签：Stage1 · 3×Bottleneck  
   - 通道旁注：256-d  
   - 出：\(F_1\)

4. **残差阶段 2（画 4 层薄片，略长）**  
   - 标签：Stage2 · 4×Bottleneck  
   - 通道旁注：512-d  
   - 出：\(F_2\)

5. **残差阶段 3（画 6 层薄片，明显最长最厚）**  
   - 标签：Stage3 · 6×Bottleneck  
   - 通道旁注：1024-d  
   - 出：\(F_3\)

6. **残差阶段 4（画 3 层薄片）**  
   - 标签：Stage4 · 3×Bottleneck  
   - 通道旁注：2048-d  
   - 出：\(F_4\)

7. **全局平均池化（小虚线框）**  
   - 标签：GAP  
   - 箭头：\(F_4 \rightarrow F_{i,t}\)  
   - 短标签：单帧空间特征 \(F_{i,t}\)

骨干箭头链必须可见：  
\(X_{i,t} \rightarrow F_1 \rightarrow F_2 \rightarrow F_3 \rightarrow F_4 \xrightarrow{\mathrm{GAP}} F_{i,t}\)

**不要**在骨干末端画「多帧平均聚合」——帧聚合是区 C 的 UWA，不是骨干内 mean。

#### B2. 帧级 EDL（画推导链，禁止公式墙）

从 \(F_{i,t}\) 向右画 4 个小节点（每节点标题 ≤6 字）：

1. 证据头：\(F_{i,t} \rightarrow e_{i,t}\)  
2. 狄利克雷：\(\alpha_{i,t}=e_{i,t}+1\)  
3. 强度：\(S_{i,t}=\sum \alpha_{i,t}\)  
4. 三叉输出（细实线，均标符号）：  
   - \(u_{i,t}=K/S_{i,t}\)（不确定度）  
   - \(p_{i,t}\)（帧阳性概率）  
   - \(\alpha_{i,t}\)（供聚合）

读者应一眼看到：\(F \Rightarrow e \Rightarrow \alpha \Rightarrow (u,p)\)。

---

### 区 C｜聚合与决策（标题：C. 窗内 UWA · 窗间 Mean · 训练目标）

**排版红线：明确「窗内 vs 窗间」两层；UWA≠Mean。**

#### C1. 窗内 · UWA（双实线关键框）

- 入（细实线）：\(\{u_{i,t},\alpha_{i,t}\}\)（来自区 B）  
- 框标题：UWA（不确定加权聚合）  
- 框内短公式一行：\(w=\mathrm{softmax}((1-u)/\tau)\)，醒目标注 \(\tau=0.5\)  
- 箭头旁短标签：窗内加权  
- 出：窗分 \(p^{(k)}\)（训练时亦可标 \(p_{\mathrm{bag}}\)）  
- **输出是概率/倾向分，不要写成「窗级特征向量再进分类器」**

#### C2. 推理 · 六窗与窗间 Mean（双实线关键框）

- 在 \(p^{(k)}\) 背后淡淡叠 5 个影（共 6）；加粗标注 **×6 扫描窗**  
- 六路 \(p^{(1)}\ldots p^{(6)}\) 汇入：**六窗平均**  
- 短公式：\(p_{\mathrm{pat}}=(p^{(1)}+\cdots+p^{(6)})/6\)  
- 旁注唯一说明句：「UWA=窗内；Mean=窗间」  
- 终点：\(p_{\mathrm{pat}}\) → 短标签「患者连续分（ROC/AUC）」  
- 半行表注：「硬分类另设阈值；AUC 扫全阈值」

#### C3. 训练损失（细虚线，勿占主链中心）

从训练路径的 \(p_{\mathrm{bag}}/\alpha\) 引出细虚线到两个小框：

- \(L_{\mathrm{main}}\)：患者级证据分类  
- \(L_{\mathrm{MIL}}\)：帧级 MIL 辅损，标注权重 **0.3**（阳性袋至少一处够阳）  
- 极小：\(L=L_{\mathrm{main}}+\lambda L_{\mathrm{MIL}}\)，\(\lambda=0.3\)

**禁止**画「MIL 分类器 → 最终预测」作为主输出；最终预测是 \(p_{\mathrm{pat}}\)（或训练时 \(p_{\mathrm{bag}}\)）。

#### C4. EMA（独立虚线悬浮角注，非图像支路）

- 右上角细虚线圆角框：EMA 参数平滑  
- 标注：decay \(=0.99\)（不要写 \(\alpha=0.99\)，避免与狄利克雷 \(\alpha\) 混淆）  
- 细虚线指向区 B 骨干：\(\theta \rightarrow \theta_{\mathrm{EMA}}\)  
- 表注：「验证/存盘/外测用 \(\theta_{\mathrm{EMA}}\)」

## 已修正：Gemini 原稿的主要问题

| 问题 | 为何错 | 正确画法 |
|------|--------|----------|
| 把 **MIL@0.3** 画成末端「MIL 分类器」 | 0.3 是**辅损权重**，不是分类头 | 损失虚线支路 \(L_{\mathrm{MIL}}\)；终点是 \(p_{\mathrm{pat}}\) |
| UWA 输出「窗级特征」再 Mean 特征 | 实现是对窗**分/概率**做 mean | UWA→\(p^{(k)}\)；Mean→\(p_{\mathrm{pat}}\) |
| Backbone 未展开 / 阶段画成一样 | ResNet50 块数 3/4/6/3 | Stage3 必须最长（6 块） |
| 骨干末端「多帧平均」 | 与 UWA 叙事冲突 | 骨干只到 \(F_{i,t}\)；聚合在区 C |
| EMA 写成 \(\alpha=0.99\) | 易与 Dirichlet \(\alpha\) 混 | 写 decay=0.99 / \(\theta_{\mathrm{EMA}}\) |
| 训练袋与推理六窗混在同一条链 | 协议不同 | 区 A 上下分训练/推理 |
| 缺箭头变量、缺 EDL 链 | 规格硬性要求 | \(F\Rightarrow e\Rightarrow\alpha\Rightarrow(u,p)\) |
| 标题偏「鲁棒 MIL」 | MIL 非主卖点 | 点位袋 + EDL-UWA + 六窗平均 |
