1. **判定：假注意力 / 近均匀** — external 中 \(n_{\mathrm{eff}}>10\) 占 **88.4%**，整体均值 11.18（均匀=12）。

4. **再堆结构（多头/更深）意义不大**；下一刀应 **逼稀疏**（降 τ / entropy penalty / top-k / gated×(1−u)）或 **换 query**。
